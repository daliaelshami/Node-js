# Node.js & Mongoose MicroApps

This repository contains my solutions for the Node.js & Mongoose assignment.  
It has 5 small backend tasks to practice using Node.js and Mongoose.

---

## Tasks

### Task 1: To-Do List
- Create tasks with title and isCompleted (default false)  
- POST /api/tasks  
- GET /api/tasks  

### Task 2: Contact Manager
- Create contacts with fullName, phones array, and socialMedia object  
- POST /api/contacts  
- GET /api/contacts  

### Task 3: Library System
- Author and Book models with relationships using ObjectId and ref  
- POST /api/authors  
- POST /api/books  
- GET /api/books (with populate)  

### Task 4: Product Inventory
- Products with name, category, price  
- Can filter products using query parameters  
- POST /api/products  
- GET /api/products?category=Electronics  

### Task 5: Classroom
- Students and Classrooms with One-to-Many relationship  
- POST /api/students  
- POST /api/classrooms  
- GET /api/classrooms (with populate)
